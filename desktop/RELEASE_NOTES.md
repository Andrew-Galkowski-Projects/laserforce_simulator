## Laserforce Simulator for Windows

The Desktop App runs the Laserforce Simulator on one Windows PC, for one person. It has the
single-player modes: Sandbox and the Single-player League. You need no account and no server.

### Install

1. Download
   [LaserforceSimulator-windows-x64.zip](https://github.com/Andrew-Galkowski-Projects/laserforce_simulator/releases/latest/download/LaserforceSimulator-windows-x64.zip).
2. Unzip it anywhere you like.
3. Open the `LaserforceSimulator` folder and run `LaserforceSimulator.exe`.

The app is not signed yet, so Windows SmartScreen may say "Windows protected your PC". Choose
**More info**, then **Run anyway**.

### Your data

Your saved data lives in `%LOCALAPPDATA%\LaserforceSimulator`. Copy that folder to back it up.

### Upgrade

Download the new zip, unzip it and run the new `LaserforceSimulator.exe`. You can delete the old
folder. An upgrade may reset your saved data; the app says so when it does.

Once per launch, the app asks GitHub whether a newer build exists. If one does, a banner links to
it. If you are offline, the app works as before.

### Uninstall

Delete the `LaserforceSimulator` folder you unzipped, and the `%LOCALAPPDATA%\LaserforceSimulator`
folder.
